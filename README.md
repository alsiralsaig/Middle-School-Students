# منصة الطالب السوداني الذكية — الصف الثالث المتوسط

مستودع أحادي (Monorepo) يضم **تطبيقين منفصلين تماماً** يتشاركان حزمة هوية واحدة.

```
ms-students/
├── shared/            # حزمة مشتركة: الهوية، الأنواع، المحتوى التجريبي (بدون خطوة بناء)
├── apps/
│   ├── student/       # تطبيق الطالب   → المنفذ 3000
│   └── admin/         # تطبيق الإدارة  → المنفذ 4000
└── scripts/           # سكربتات المحتوى وتشغيل التطبيقين
```

## التشغيل

```bash
npm install                 # مرة واحدة (من الجذر — يستخدم npm workspaces)

npm run dev:student         # تطبيق الطالب  → http://localhost:3000
npm run dev:admin           # تطبيق الإدارة → http://localhost:4000
npm run dev:all             # الاثنان معاً
```

## البناء والتحقق

```bash
npm run build:student       # بناء تطبيق الطالب
npm run build:admin         # بناء تطبيق الإدارة
npm run lint                # فحص الأنواع في التطبيقين
npm run content:check       # التحقق من سلامة ملفات المحتوى (apps/student/src/content)
```

## الحزمة المشتركة `@ssp/shared`

| الملف | المحتوى |
|---|---|
| `brand.ts` | اسم المنصة، الصف، والألوان الرسمية (كحلي `#002368`، ذهبي `#F1AC12`) |
| `brand.css` | متغيرات CSS وأصناف جاهزة مشتقة من الهوية |
| `types.ts` | الأنواع المشتركة، وأهمها `ContentStatus` لتمييز المحتوى |
| `sampleContent.ts` | بيانات تجريبية للعرض والتجربة |
| `assets/` | الشعار والبانر الرسميان |

### قاعدة المحتوى

كل عنصر محتوى يحمل حقل `status`:

- `sample` → محتوى تجريبي للعرض، **يجب** وسمه للطالب.
- `verified` → محتوى مُطابق للمنهج السوداني المعتمد.

## ما هو مُفعّل في المرحلة الأولى؟

| الميزة | الحالة |
|---|---|
| عرض المواد والوحدات والدروس | ✅ يعمل |
| التنقّل وتصميم الجوال (عربي RTL) | ✅ يعمل |
| المكتبة (عرض) | ✅ يعمل — الرفع غير مُفعّل |
| الاختبارات | ⚠️ واجهة تجريبية — التصحيح والحفظ غير مُفعّلين |
| المساعد الذكي | ⚠️ واجهة استعراضية — **غير متصل** بأي خدمة ذكاء اصطناعي |
| لوحة الإدارة | ⚠️ واجهة تحضيرية — الحفظ يتطلب قاعدة بيانات |
| قاعدة البيانات / الحسابات / الدفع | ❌ غير موجودة في هذه المرحلة |
