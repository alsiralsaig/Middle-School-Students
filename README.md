# منصة الطالب السوداني الذكية 🇸🇩

منصة تعليمية لطلاب **الصف الثالث المتوسط (الشهادة المتوسطة)** بالمنهج السوداني:
شروحات تفاعلية · مكتبة مذكرات · بنك امتحانات تجريبي · معلم ذكي بالذكاء الاصطناعي.

---

## 🚀 التشغيل السريع

### بـ npm (الأساسي)

```bash
npm install
cp .env.example .env     # ثم ضع مفتاح Gemini في .env
npm run dev              # http://localhost:3000
```

### بـ bun

```bash
bun install
cp .env.example .env
bun run dev
```

> ⚠️ **مهم:** لا تخلط بين مديري الحزم. المشروع فيه `package-lock.json` (npm)،
> فإذا كنت تستخدم bun احذفه أولاً، والعكس صحيح.

### الإنتاج

```bash
npm run build
npm start                # يخدم dist/ على المنفذ 3000
```

## 🔑 متغيرات البيئة

أنشئ ملف `.env` في الجذر (انسخ من `.env.example`):

| المتغير | مطلوب؟ | الوصف |
|---|:---:|---|
| `GEMINI_API_KEY` | ⚠️ اختياري | مفتاح Google Gemini للمعلم الذكي. بدونه يعمل بديل تربوي جاهز |
| `PORT` | لا | منفذ السيرفر (افتراضي 3000) |
| `NODE_ENV` | لا | `production` لخدمة `dist/` |
| `AI_RATE_MAX` | لا | أقصى طلبات AI لكل IP في 10 دقائق (افتراضي 20) |
| `AI_DAILY_CAP` | لا | سقف طلبات AI في اليوم لكل السيرفر (افتراضي 2000) |

## 📜 الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | سيرفر التطوير (Vite + Express) |
| `npm run build` | بناء الإنتاج في `dist/` |
| `npm start` | تشغيل الإنتاج |
| `npm run lint` | فحص الأنواع (`tsc --noEmit`) |
| `npm run content:check` | ✅ فحص محتوى المنهج (لازم يمر قبل أي رفع) |
| `npm run content:export` | تصدير `curriculumData.ts` → ملفات JSON |
| `npm run verify` | الشامل: أنواع + محتوى + بناء |

## 📁 بنية المشروع

```
src/
├── content/          ← ⭐ محتوى المنهج (ملف JSON لكل مادة) — عدّل هنا فقط
├── data/             ← بيانات التطبيق (مذكرات، امتحانات، إنجازات)
├── views/            ← الشاشات الرئيسية
├── components/       ← مكوّنات الواجهة
├── context/          ← الحالة العامة (الحساب، اللغة)
├── utils/            ← أدوات (طباعة المذكرات، الترجمة)
└── types/            ← أنواع TypeScript
server.ts             ← سيرفر Express + واجهة Gemini المحمية
public/               ← ملفات PWA (manifest, service worker, أيقونات)
scripts/              ← سكربتات المحتوى (تصدير/فحص)
```

**📚 لإضافة درس أو وحدة: راجع [`CONTENT_GUIDE.md`](./CONTENT_GUIDE.md)**
— لا تحتاج تلمس أي كود.

## 🛡️ الحماية

واجهات الذكاء الاصطناعي (`/api/gemini/*`) محمية بـ:

- **تحديد معدل:** 20 طلب / 10 دقائق لكل IP (قابل للضبط بـ `AI_RATE_MAX`)
- **سقف يومي عام:** 2000 طلب / يوم (قابل للضبط بـ `AI_DAILY_CAP`) — صمّام أمان للمفتاح
- **حدود الإدخال:** السؤال 1200 حرف · سياق الدرس 4000 · التاريخ 4 رسائل
- **تنظيف المدخلات:** قص المحارف التحكمية قبل تمريرها للنموذج

> ملاحظة: العدّاد في الذاكرة. على أكثر من نسخة سيرفر استخدم مخزناً مشتركاً (Redis).

## 📱 PWA

التطبيق يُثبّت على الهاتف ويفتح **بدون إنترنت**:

- `public/manifest.webmanifest` — الاسم والأيقونات واختصارات المواد والامتحانات
- `public/sw.js` — تخزين التطبيق والملفات؛ الصفحات offline-first وطلبات AI شبكة فقط
- `public/offline.html` — شاشة واضحة عند انعدام الاتصال

يُسجَّل الـ Service Worker في **الإنتاج فقط** (لا يعطّل التطوير بالكاش).

## ⚠️ ملاحظات قبل النشر للطلاب

1. البيانات التجريبية (لوحة الشرف، غرف المذاكرة) ما زالت **ثابتة في الكود** للتجربة — احذفها أو اربطها بحسابات حقيقية قبل الإطلاق.
2. `unitsCount` / `lessonsCount` في كل مادة **معلنة** وليست فعلية — حدّثها مع كل درس تضيفه.
3. لوحة الإدارة حالياً بلا تسجيل دخول — أخفها أو احمها قبل النشر.
