# الامتحانات التجريبية — صيغة الملف

ملف واحد لكل مادة: `shared/exams/<subject-id>.json`

```json
{
  "subjectId": "math",
  "exams": [
    {
      "title": "امتحان تجريبي ١ — الرياضيات",
      "durationMinutes": 60,
      "status": "sample",
      "sourceNote": "من إعدادنا على نموذج ورقة ولاية نهر النيل ٢٠٢٤",
      "answerKey": "الحل الكامل سطراً سطراً مع الدرجة لكل سؤال…",
      "questions": [
        {
          "question": "نص السؤال؟",
          "options": ["الخيار أ", "الخيار ب", "الخيار ج", "الخيار د"],
          "correctIndex": 1,
          "explanation": "التبرير — يظهر للطالب بعد التسليم"
        }
      ]
    }
  ]
}
```

## القواعد

- **٥ امتحانات + ٥ مفاتيح إجابة لكل مادة** (٩ مواد → ٤٥ امتحاناً).
- `correctIndex` فهرس الإجابة الصحيحة في `options` (يبدأ من ٠).
- `answerKey` الحل الكامل — يُحفظ كمورد في المكتبة («مفتاح إجابة»).
- `status`: `sample` لإعدادنا، `verified` فقط لورقة وزارية منشورة.
- الوسم الصدق إلزامي: أي ورقة ليست من الوزارة تُسمّى «نموذج من
  إعدادنا» لا غير — انظر `official/SOURCES.md`.

## الاستيراد

```bash
python3 scripts/db_exams.py        # كل المواد
python3 scripts/db_exams.py math   # مادة واحدة
```

آمن تماماً: رفع فقط، بلا حذف، ولا يمسّ الطلاب ولا محاولاتهم.

## حالة الحزمة الحالية

اكتملت الحزمة الأولى: ٤٥ امتحاناً جديداً و٤٥ مفتاح إجابة (٥ لكل مادة من مواد المنصة).
كلها من إعدادنا وموسومة بوضوح؛ الإنجليزية مبنية على نموذج TiT الخاص وليست ورقة وزارية.
مراجعات `civics` الخمس إثرائية للصف الثاني فقط (`supplemental`) وليست من شهادة الثالث.
